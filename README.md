# あいうえおちょう

5歳前後の子どもが、ひらがな・カタカナを見て、聞いて、書いてみるための静的PWAです。外部ライブラリやアプリ用サーバーを使わず、GitHub Pagesで配布できます。

## GitHub Pagesへの公開

1. このフォルダーをGitHubリポジトリの `main` ブランチに追加します。
2. リポジトリの **Settings → Pages → Build and deployment** で、Sourceを **GitHub Actions** に設定します。
3. `main` へのpush、またはActions画面からの手動実行でデプロイします。
4. GitHub Actionsの `Deploy to GitHub Pages` が完了したら、表示されたPages URLをSafariで開きます。
5. iPadではSafariの共有メニューからホーム画面に追加します。
6. 初回はネット接続中にアプリを開き、「じゅんびする」を完了させてからオフライン動作を利用します。

このアプリはリポジトリのサブパス配下（通常の `username.github.io/repository/` 形式）でも動く相対パス構成です。PWAはHTTPS配信が必要です。横向き固定には依存せず、縦向き時も主要画面を表示します。

## 現在の収録範囲

- 基本ひらがな46字、カタカナ46字の一覧と書き順SVG
- ひらがな16語、カタカナ16語のおまかせ出題。ことばは一つの練習枠に続けて書く
- 右から左へ列が進み、各列を上から下へ読むかな表
- タッチ操作・タッチペンに対応した筆跡キャンバス、取り消し、消去
- 手本を隠して書く練習、読み上げ、端末内の練習記録、シール
- アプリ画面とかなSVGを端末へ保存する初回オフライン準備

読み上げはブラウザ/OSの日本語音声合成を使い、端末が提供する日本語の声を選べます。声質やオフライン動作は端末に依存するため、iPadに日本語音声をダウンロードして確認してください。イラストには端末内蔵の絵文字を使っています。自動の文字採点、ことば教材の追加、独自の画像素材制作は未収録です。濁音・半濁音・小さいかな・長音は、収録したことばでお手本と練習用の字形を表示します。

## データとプライバシー

練習回数、進捗、獲得シール、音声設定は `localStorage` に保存します。サーバー送信・アカウント・同期はありません。SafariやiPadのデータ消去、端末故障、ブラウザの保存領域整理による消失を防ぐバックアップ機能はありません。

## 書き順データのライセンス

`assets/strokes/` の基本かなSVGは [AnimCJK](https://github.com/parsimonhi/animCJK) のデータを利用し、SVG内にも著作権者とライセンス表示を残しています。かなSVGはLGPL v3-or-laterで配布されます。ライセンス本文と上流の配布条件は [`licenses/`](./licenses/) を参照してください。

## iPadでの確認

最低対応iPadOS/Safariの範囲は未確定です。公開前に使うiPadで、ホーム画面追加、オフライン準備、再起動後のオフライン起動、音声、Apple Pencil等の筆跡入力を確認してください。画面方向ロックは保証せず、向きに応じたレスポンシブ表示を行います。
